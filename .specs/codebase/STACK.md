# Technology Stack

## Runtime & Languages

- **Language**: TypeScript 5.x+ (strict mode, decorators com `experimentalDecorators: true` e `emitDecoratorMetadata: true`)
- **Runtime**: Node.js 18+ / Bun / Turbopack / Next.js 14+ (App Router, Server Actions, RSC)
- **Metadata Reflection**: `reflect-metadata`

## Target Frameworks & Ecosystem

- **Next.js**: 14.x / 15.x+
- **React**: 18.x / 19.x (Server Components, Client Components, Hooks)

## Package Management & Build

- **Package Manager**: pnpm / npm / yarn
- **Build Tool**: tsdown (rolldown / oxc)
- **Test Runner**: Vitest (suporte nativo a ESM e decorators TypeScript)
